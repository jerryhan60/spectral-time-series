# Dataset Setup

## LOTSA (training data)
See Uni2TS documentation. Set LOTSA_V1_PATH in uni2ts/.env.

## GIFT-Eval (evaluation)
Set GIFT_EVAL path in uni2ts/.env. 97 dataset x horizon configurations.

## FEV-Bench (evaluation)
Install via: pip install autogluon-fev
Datasets are downloaded automatically on first use.

Smoke tests do not require any of these datasets.
